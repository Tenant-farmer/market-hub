# 리서치 체크리스트 — 검증 시작 전 5분

> 백테스트·팩터 검증·전략 판단을 **시작하기 전에** 훑는다.
> 수록된 함정은 전부 **이 프로젝트에서 실제로 발생한 것**이다 (날짜·사례 명시).

---

## 시작 전 (데이터)

- [ ] **캐시 기간·종목수를 눈으로 확인했나?**
  실제 사고(2026-07-27): 라이브용 400일 캐시가 11년 백테스트 캐시를 덮어써, 검증이
  1.5년 구간으로 조용히 돌았다. → `scripts/_bt_cache.py` 가드가 이제 5년·200종목 미달 시 중단.
  가드를 우회하는 새 스크립트를 쓸 땐 **기간을 직접 출력**할 것.

- [ ] **생존편향을 인지했나?**
  우리 유니버스는 **현재 S&P500 구성**이다 = 상폐된 패자가 없고, 미래 승자를 미리 안다.
  절대 수익률은 **항상 과대평가**. 판정은 "SPY 대비" 또는 "동일가중(EW) 대비"로만.
  실측(reality_check): EW가 SPY를 이기는 +3.4%p/년이 **순수 생존편향분**.

- [ ] **look-ahead가 없나?**
  - 신호는 당일 종가로 판정 → 체결은 **다음 날** (우리 규약)
  - 재무·퀄리티 데이터가 **현재 스냅샷**이면 과거 시점엔 알 수 없던 정보다.
    실제(2026-07-27 퀄리티 검증): 정적 퀄리티라 IC가 과대 — 결론에 caveat 명시했다.

- [ ] **표본이 충분한가?** 에피소드 8개짜리 결론과 3만 건짜리 결론을 같은 확신으로 말하지 말 것.

## 검증 중 (방법)

- [ ] **IC만 보고 팩터를 버리지 않았나?** ⚠️ 가장 비싼 교훈
  실제(2026-07-27): rs63 IC = **-0.010(무의미)** 인데 백테스트는 +1783%.
  원인은 모멘텀이 **U자**였기 때문 — D1 +6.0% / 중간 +4% / D10 +6.5%.
  스피어만 IC는 **단조 관계만** 측정해서 양극단 알파를 못 본다.
  → 팩터 판정은 **IC + 분위 단조성 + 상위N 실측** 3종을 함께.

- [ ] **파라미터를 몇 개나 건드렸나?** 스윕 27개 중 최고를 고르면 그건 이미 과최적화 후보다.
  민감도(고원)가 있는지 확인: 실제(낙폭 컷 3/5/7/10%) 3~7%가 고원 → -5%는 견고, -10%는 파괴.

- [ ] **복잡하게 만들어서 좋아졌나?** 우리 데이터의 일관된 답은 **"아니오"**:
  - 복합점수(6성분) < 3개월 단독 (universe_compare)
  - 모멘텀+퀄리티 < 모멘텀 단독 (quality_factor)
  - 단타 6전략 중 4개가 SPY 미달 (swing 6-strategy)

- [ ] **비용을 현실적으로 넣었나?** 편도 5bp는 낙관. 100bp면 모멘텀 알파가 소멸(reality_check).
  회전율이 높은 전략일수록 비용에 죽는다.

- [ ] **레짐을 쪼개봤나?** 전 기간 평균은 거짓말한다.
  모멘텀은 2019 -8%p·2021 -3%p·2022 -9%p로 **역행**했다(연도별 IC도 동일 확인).

## 결론 낼 때 (해석)

- [ ] **내가 원하던 답이 나와서 멈춘 건 아닌가?** (확증편향)
  반례를 한 번은 찾아볼 것. 실제: "모멘텀은 평온장이 유리"라는 내 가설이 데이터로 **기각**됐다
  (timing_by_vix — 두 전략 다 공포장 VIX≥30에서 승률 70%+).

- [ ] **모순을 덮지 않았나?** IC 음수 vs 백테스트 양수처럼 **충돌이 보이면 그게 발견의 입구**다.
  덮지 말고 진단 스크립트를 짜라.

- [ ] **이 수익이 실력인가 시장인가?** α/β로 분해(`src/analytics/attribution.py`).
  β 1.2면 그만큼은 실력이 아니다.

- [ ] **최악을 숫자로 말할 수 있나?** VaR/CVaR/MC 낙폭(`src/analytics/risk.py`).
  실측: 모멘텀은 **1년 내 -20% 낙폭 확률 30.6%**. 모르고 시작하면 바닥에서 판다.

- [ ] **표본 밖에서도 될까?** 미국에서 된 게 한국에서 안 된 실제 사례:
  동일 로테이션 규칙이 US +6042% / KR -61~-74%.
